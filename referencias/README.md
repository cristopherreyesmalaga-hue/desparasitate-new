# Referencias

Pon aquí lo que quieres que `/crear-web` tenga en cuenta antes de diseñar.

- **Imágenes**: capturas de webs que te gustan, fotos de tu producto, tu logo (`.jpg`, `.png`, `.webp`).
- **Vídeos**: grabaciones de pantalla de una web o reels (`.mp4`, `.mov`). Se extraen fotogramas
  para ver composición y animaciones.
- **Enlaces**: escríbelos en `enlaces.md`, uno por línea, con una nota de qué te gusta de cada uno.

También puedes adjuntarlos directamente en el chat al escribir `/crear-web`.

Para subir archivos desde el móvil o la tablet: en GitHub abre esta carpeta, pulsa
**Add file → Upload files** y confirma con **Commit changes**.

Las webs de referencia son inspiración: no se copian sus textos, logos ni imágenes. Tus propias
fotos y tu logo sí se usan en la página.
